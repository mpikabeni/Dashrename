# DASH FILEBOT

DASH est un gestionnaire de fichiers Telegram créé par **NEXA**.

## Fonctionnalités

- ✏️ Renommer les fichiers
- 🎬 Gestion des vidéos
- 🖼️ Miniatures personnalisées
- 📦 Traitement des fichiers
- ℹ️ Informations sur les fichiers
- 📜 Historique des renommages
- 📢 Diffusion administrateur
- 👥 Gestion des utilisateurs
- 🔐 Vérification de l'abonnement NEXA
- 🗄️ Stockage Backblaze B2
- ⚡ FFmpeg / FFprobe

## Installation

pip install -r requirements.txt
